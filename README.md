# ॐ Gayathri Japam Counter

A lightweight, responsive web application designed for tracking daily Gayathri Mantra Japam sessions with custom targets, local storage persistence, and visual completion overlays.

## Features

* **Target Flexibility:** Easily switch between 108 and 1008 chant targets.
* **Progress Tracking:** Dynamic circular SVG progress ring and session timer.
* **Tactile & Sound Feedback:** Haptic vibration on tap (mobile) and automatic conch audio on completion.
* **State Persistence:** Automatically saves your session count and elapsed time locally (`localStorage`).
